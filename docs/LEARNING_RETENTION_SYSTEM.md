# JUBA LISAN — Learning & Retention System

## Objective

The learning system should maximize durable recall and real-world language ability. Completion, XP and streaks are secondary signals.

## Daily loop

1. **Resume** — continue the most relevant unfinished activity.
2. **Recall** — review due vocabulary, grammar or phrases before introducing too much new material.
3. **Learn** — introduce a small, level-appropriate concept.
4. **Practice** — apply it through reading, listening, writing or speaking.
5. **Correct** — explain errors and record recurring weaknesses.
6. **Speak** — use the target material in contextual conversation with JUBA AI Tutor.
7. **Reflect** — show mastery, retention and the next recommended action.

## Review priority

The recommendation engine should prioritize items using signals such as:

- due date / scheduled review
- recent recall failures
- repeated mistakes
- confidence or mastery score
- time since last successful recall
- relevance to the learner's current curriculum

## Skill model

Track progress independently for:

- Vocabulary
- Grammar
- Listening
- Reading
- Writing
- Speaking
- Pronunciation
- Retention

A learner can therefore be strong in vocabulary while still needing targeted speaking practice.

## Motivation model

Gamification should reinforce useful behavior:

- daily goals
- meaningful milestones
- mastery celebrations
- streak protection based on completed learning, not app opens
- gentle recovery after missed days

Avoid manipulative loops, excessive notifications and rewards for meaningless taps.

## Dashboard contract

The signed-in home screen should surface, in order of importance:

1. Today's goal and completion state.
2. Continue learning action.
3. Reviews due today.
4. Weak-skill recommendation.
5. Speaking/conversation practice.
6. Skill mastery and retention trend.
7. Secondary achievements and history.

## Accessibility and localization

All learning and motivation components must support keyboard navigation, reduced motion, responsive layouts and full RTL localization.
