# إنشاء أسعار JUBA LISAN في Stripe Test Mode

هذا السكربت ينشئ منتجين وأربعة أسعار اختبار فقط: Go بسعر 7.99 EUR شهريًا أو 79.99 EUR سنويًا، وPlus بسعر 14.99 EUR شهريًا أو 149.99 EUR سنويًا. Free لا يحتاج منتج Stripe. تجربة Go دون بطاقة يصدرها التطبيق، ولا تُضاف مدة تجربة إلى أسعار Stripe.

## التشغيل

نفّذ من جذر المستودع داخل بيئة backend التي ثبتت `backend/requirements.txt`، وباتصال إنترنت. لا يلزم تشغيل قاعدة البيانات أو التطبيق لإنشاء الأسعار.

1. معاينة دون مفتاح أو اتصال:

```bash
python backend/scripts/bootstrap_stripe_test_prices.py
```

2. افتح حساب Stripe الصحيح في وضع Test Mode أو Sandbox. ضع مفتاحه السري في `STRIPE_SECRET_KEY` عبر مدير الأسرار. بديل تفاعلي في Bash، لا يكتب المفتاح في سجل الأوامر:

```bash
read -r -s -p 'Stripe TEST secret key: ' STRIPE_SECRET_KEY
printf '\n'
export STRIPE_SECRET_KEY
python backend/scripts/bootstrap_stripe_test_prices.py --apply
unset STRIPE_SECRET_KEY
```

يرفض السكربت مفاتيح live وpublishable. يقبل `sk_test_`، أو `rk_test_` مع صلاحيات قراءة وكتابة المنتجات والأسعار. لا تمرر المفتاح كوسيط، ولا ترسله في المحادثة، ولا تضعه في Git أو frontend.

3. عند النجاح تُطبع أربعة أسطر إعدادات فقط إلى stdout:

```dotenv
STRIPE_PRICE_GO_MONTHLY=price_...
STRIPE_PRICE_GO_YEARLY=price_...
STRIPE_PRICE_PLUS_MONTHLY=price_...
STRIPE_PRICE_PLUS_YEARLY=price_...
```

انسخ القيم الناتجة إلى إعدادات **backend الاختباري فقط** مع مفتاح Stripe الاختباري الموافق و`STRIPE_ENABLED=true`، ثم أعد تشغيل backend لتحميل الإعدادات. لا تستخدم معرّفات الاختبار مع مفتاح live. لا تستبدل `STRIPE_PRICE_MONTHLY/YEARLY` القديمة إذا كنت تحتاج التعرف على اشتراكات قديمة.

## إعادة التشغيل والفشل

يستخدم السكربت معرّفات منتجات ثابتة، وlookup keys للأسعار، وidempotency keys. إعادة تشغيله بنفس حساب الاختبار تعيد استخدام العناصر المطابقة. يتحقق من العملة والمبلغ ودورة التجديد وحالة السعر ونمط الاختبار قبل إنشاء عناصر جديدة؛ التعارض يوقف التنفيذ ولا يعدل أو يؤرشف السعر الموجود. المنتجات والأسعار التي أنشئت قبل انقطاع الشبكة تبقى في Stripe؛ أعد التشغيل بنفس الحساب لاستكمال الناقص. لا يوجد حذف تلقائي أو ضمان معاملة ذرية عبر كل طلبات Stripe.

الحماية من نمط live موجودة في هذا السكربت فقط. استخدم بيئة تطبيق معزولة وقاعدة بيانات اختبار، ولا توصلها ببيانات المستخدمين الحقيقيين.

## اختبارات السكربت

من جذر المستودع:

```bash
python -m unittest discover -s backend/scripts/tests -p 'test_*.py' -v
```

تستخدم محاكاة Stripe، لا حسابًا حقيقيًا. تغطي رفض المفاتيح غير الاختبارية، الأسعار الأربعة، إعادة التشغيل، التعارض، فشل lookup، واستكمال إنشاء جزئي. كما تقارن المبالغ بكتالوج التطبيق عند وجود المستودع كاملًا.

## حدود التحقق

نجحت سبعة اختبارات محلية بالمحاكاة وقت إضافة السكربت. اختبار مقارنة كتالوج التطبيق لم يُشغّل في بيئة الملفات المعزولة. لم يحدث اتصال Stripe أو إنشاء أسعار فعلية هنا؛ لا تدّعي نجاح رحلة الدفع من هذه الاختبارات. إنشاء الأسعار لا يُنشئ اشتراكًا أو عملية تحصيل، ولا يُجهز webhook أو Customer Portal تلقائيًا.

بعد الإعداد، يلزم اختبار مستقل في بيئتك لشراء الخيارات الأربعة عبر Checkout، تفعيل tier بعد webhook موقّع، إلغاء الاشتراك وتجديده وفشل الدفع وإعادة إرسال الأحداث. هذا السكربت ليس اختبارًا شاملًا لتلك الرحلة.

مراجع Stripe: https://docs.stripe.com/api/prices/create ، https://docs.stripe.com/api/idempotent_requests ، https://docs.stripe.com/api/prices/list .
